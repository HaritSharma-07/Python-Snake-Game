# Snake Game

A classic Snake Game built using Python's Turtle graphics module. This project was created as part of my Python learning journey.

## Features

- Control the snake using the arrow keys.
- Snake grows after eating food.
- Random food generation.
- Collision detection with walls and the snake's body.
- Score and high score tracking.
- High score is stored using a text file.

## Technologies Used

- Python
- Turtle Graphics
- Object-Oriented Programming (OOP)
- File Handling

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/snake-game.git
```

2. Open the project folder.

3. Run the following command:

```bash
python main.py
```
